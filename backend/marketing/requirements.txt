# marketing/requirements.txt — the MEDIA WORKER image (marketing/Dockerfile), NOT the web
#
# Why a separate file: the worker's ML stack (Kokoro TTS + torch-cpu + misaki/spaCy) must never
# land in the single-uvicorn web image — it is ~1 GB of packages the request path never uses, and
# the whole point of the split is that the ML-heavy process holds no Supabase key and no social
# secrets.
#
# torch is installed by the Dockerfile FROM THE CPU INDEX before this file
# (`--index-url https://download.pytorch.org/whl/cpu`): the 184 MB CPU wheel instead of the
# 767 MB CUDA one, and the Dockerfile asserts no nvidia-* package slipped in. The pin here keeps
# the resolver from replacing it.
#
# Versions are the ones measured together in the 2026-09-26 spike (backend/venv_marketing):
# kokoro 0.9.4 + misaki 0.9.4 gave the token shapes marketing/timings.py is written against —
# bump them together with voice.PIPELINE_VERSION and re-run `python -m marketing.preview`.
