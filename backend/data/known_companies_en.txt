# Known companies and consumer brands, one per line, AS WRITTEN (case is significant).
#
# Used by the marketing validators (app/services/marketing/compliance.py `company_mentions`,
# grounding.py `_check_companies`). Two jobs:
#   1. A company name that is ALSO an English word ("Apple", "Target", "Visa", "Oracle", "Coke")
#      passes the grounding dictionary as ordinary vocabulary. Listed here, written capitalised in
#      a name position, it is an ENTITY: it must be a company this item's fact sheet itself names.
#   2. A sentence that names a company runs the full class-B scan in every mode (a Journey post
#      has no named instrument by design; one that names a company gets the Money Moves rules),
#      and the company is the instrument for the directive / verdict / forecast / price-move
#      rows ("Buy NVIDIA", "Costco is a great investment", "AMD will keep climbing").
#
# Compiled by hand for this repository: every company the bundled Learn corpus names (all items,
# eligible or not — `backend/data/money_moves.json`, `journey_lessons.json`) plus widely known
# listed companies and consumer brands. Company names are facts, not copyrightable expression.
#
# Syntax:
#   ~Name     an English word: a company only in a NAME position (mid-sentence capital,
#             possessive, before stock/shares/Inc, or opening a sentence as the subject of a
#             verb — "Apple has", never "Target a savings rate", "Chase returns", "Shell out").
#   Name      not an English word (the grounding dictionary does not know it): any case.
#   NAME      all capitals: matched exactly (IBM, AMD, TSMC).
#   Two Words a multi-word name: matched when every word is written capitalised, in any position.
#
# Deliberately ABSENT: generic words a headline or a sector name capitalises ("Staples",
# "Progressive", "Next", "Match", "Sea", "Grab", "Wise", "Booking", "Dow", "Nasdaq",
# "Canon", "Unity", "Compass"), index names, regulators, and people (a founder's name is a
# person, e.g. "Walt Disney" — the person rules own it).
#
# `tests/test_marketing_content_b_companies.py` pins the "~" marking against the grounding
# dictionary, so an entry cannot silently be in the wrong class.
