# marketing/requirements.txt — the MEDIA WORKER image (marketing/Dockerfile), NOT the web
#
# Why a separate file: the worker's ML stack (Kokoro TTS + torch-cpu + misaki/spaCy, Phase 3;
# Pillow pinned for card rendering, Phase 4) must never land in the single-uvicorn web image
# — it is ~1 GB of packages the request path never uses, and the whole point of the split
# is that the ML-heavy process holds no Supabase key and no social secrets.
#
# Phase 1 keeps this minimal: the worker is stdlib + httpx. Phase 3 adds (from the CPU index,
# `--index-url https://download.pytorch.org/whl/cpu`, so the 184 MB torch wheel is chosen
# over the 767 MB CUDA one): torch==2.6.0, kokoro==0.9.4 (misaki[en] bundles espeak-ng);
# Phase 4 adds Pillow (pinned — it is only transitive in requirements.txt today).
httpx[socks]==0.28.1
